# mcl_spears
# 🗡️ Spear Mod for Mineclonia (`mcl_spears`)

A complete, feature-rich spear mod designed for **Mineclonia** and **VoxeLibre**. Adds a brand-new weapon class featuring multi-tier crafting, custom charging mechanics, physics-based throwing, entity collisions, and block-sticking capabilities.

---

## ✨ Features

- **6 Material Tiers**:
  - 🪵 **Wooden Spear** (Low durability, quick early-game weapon)
  - 🪨 **Stone Spear** (Reliable basic tier)
  - ⚙️ **Iron Spear** (Standard balanced combat weapon)
  - 🪙 **Golden Spear** (Fast, highly enchantable)
  - 💎 **Diamond Spear** (High damage and extreme durability)
  - 🖤 **Netherite Spear** (Ultimate tier upgradeable via Smithing Table)
- **Charging & Throwing**: Tap and hold **Right-Click (RMB)** to cock the spear before launching it through the air.
- **Dispenser Automation**: Fully integrated with Mineclonia dispensers to throw spears automatically using Redstone logic.
- **Sticking Physics**: Thrown spears stick directly into solid blocks upon impact and can be picked up by players.
- **Full Mineclonia Integration**: Custom damage reasons, knockback physics, and native sound effects.

---

## 🛠️ Crafting Recipes

### Standard Crafting (Wood, Stone, Iron, Gold, Diamond)
Craft spears in a crafting grid using a diagonal layout:

```text
[   ] [   ] [ Material ]
[   ] [Stick] [        ]
[Stick] [   ] [        ]
Wood: Any Wooden Planks / Wood Group

Stone: Cobblestone

Iron: Iron Ingot

Gold: Gold Ingot

Diamond: Diamond

Netherite Spear Upgrade
Upgrade a Diamond Spear at a Smithing Table using:

Template: Netherite Upgrade Smithing Template

Base: Diamond Spear

Addition: Netherite Ingot

(Fallback standard recipe: 1 Netherite Ingot + 1 Diamond Spear in any crafting grid).

🎮 How to Use
Melee Attack: Left-click (LMB) to perform standard thrust attacks.

Throw Spear:

Hold Right-Click (RMB) for 0.4 seconds to charge.

Release RMB to throw the spear forward.

Retrieval: Walk up to any thrown spear stuck in a wall or ground to pick it back up into your inventory.
